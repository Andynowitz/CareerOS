# CareerOS API

CareerOS exposes a versioned REST API through FastAPI.

## Base URL

```text
http://localhost:8000
```

API endpoints are versioned under:

```text
/api/v1/
```

## Interactive Documentation

FastAPI automatically provides:

* `/docs` — Swagger UI
* `/redoc` — ReDoc
* `/openapi.json` — OpenAPI specification

For local development:

```text
http://localhost:8000/docs
```

## Main API Areas

The API currently provides functionality for:

* Authentication and sessions
* Job management
* Application activity
* Resume management
* Job analysis
* Resume analysis
* Job/resume matching
* Application insights
* Application assistant

## Authentication

Better Auth is the central authentication authority.

Protected API requests require an authenticated session. FastAPI validates the session and performs authorization and resource ownership checks.

Unauthenticated requests return:

```text
401 Unauthorized
```

## API Design

The API follows these principles:

* Versioned endpoints under `/api/v1/`
* Pydantic request/response validation
* Backend authorization
* Resource ownership checks
* SQLAlchemy database access
* Business logic separated from route handlers
* Environment-based configuration
* Explicit HTTP status codes
* OpenAPI documentation generated by FastAPI

## Health Checks

```text
GET /health
GET /api/v1/health
GET /api/v1/db-check
```

These endpoints are intended for service and infrastructure health verification.

For the complete and always-current endpoint specification, use the generated FastAPI OpenAPI documentation at `/docs`.
